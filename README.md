## 🚦 Practice Workflow Refresher
1. **Clone Repo:** `git clone [repo-url]`
2. **Create Branch:** `git checkout -b @your-username/task-name` (Example: `@favour/init-setup`)
3. **Commit Message:** `feat: added contact info`
4. **PR Title:** `[Fix]: (Task Title) #IssueNumber` (Example: `[Fix]: Initial Team Setup #1`)
5. **Description:** Add `Closes #IssueNumber` and tag your Lead (Example: `Closes #1 @Johnson`).
